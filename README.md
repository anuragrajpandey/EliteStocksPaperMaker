# EliteStocks PaperMaker

A browser-first editor for the rapid paper typography video style: scenes change quickly while one persistent main text remains locked in place.

## Current MVP

- Persistent main text
- Rapid scene text changes
- Adjustable scene speed (60–500 ms)
- 9:16 canvas preview
- Paper styles
- Optional local image per scene
- Play/pause preview
- Browser-side WebM export using MediaRecorder
- No account or backend required

## Run

Open `index.html` directly, or serve the folder with any static server.
